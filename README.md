
# Career RAG

An AI-powered career recommendation and skills-analysis system for data science students.

## Goal

The system helps students understand which data career path suits their current skills, which skills they are missing, and which portfolio projects they should build.

## Tech Stack

- Python
- UV
- Hugging Face Datasets
- ChromaDB
- LangChain
- FastAPI
- Docker
- DVC
- Streamlit
